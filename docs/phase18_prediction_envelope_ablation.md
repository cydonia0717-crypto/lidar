# 第18阶段：仿真预测误差占据包络的严格消融（PR #25）

## 实验目的

在不再引入实车数据依赖的前提下，研究在二维LiDAR-like中心检测、噪声、漏检和因果LS5速度估计下，增加动态目标占据余量能否同时改善**物理避障安全与任务完成能力**。仿真优先；未来实车迁移可以替换观测提供者、目标半径标定和不确定性来源，但本实验不代表ROS实测。

此前第18阶段固定感知实验表明：LS5在相同中心观测下明显降低目标短时预测误差，但强退化的已测种子仍全部碰撞。因此本实验仅变动一个因素：**把额外半径加到规划器所见的移动障碍物上**。保留第16阶段已验证的`two_stage_viability`、指令队列、制动和物理碰撞判据。

## 避免真值泄漏的数据流

~~~text
固定、不可变仿真真值World (物理目标半径真实值)
     ├─> 当前之前的历史目标位置 -> 带噪/漏检模拟LiDAR检测 -> 因果LS5速度估计
     │                                                        └── 额外占据半径
     │                                                             └─> 规划World
     │                                                                └─> 第16阶段规划器
     └─> 物理碰撞、道路越界和最终目标判定（完全不使用上面的额外半径）
~~~

**离线校准**读取独立的仿真真值作参考，但这一步在闭环测试之前、不同case ID的校准集合上执行，只输出预先固定的一个额外半径。闭环控制器完全看不到任何真实目标位置、真实速度或者某一次测试中的预测误差。不同包络策略使用同一个`case_id`、模拟观测随机种子与物理配置；闭环轨迹差异会改变后续雷达观测分布，这是该类控制对照的固有性质，应避免宣称每一步观测都完全相同。

## 预注册式校准和验证配置

| 内容 | 固定设置 |
|---|---|
| 物理场景 | `two_targets/weak_brake` |
| 校准种子 | 10—19（10个case，绝不参加本轮闭环测试） |
| 校准观测 | 固定直行1.5m/s、161个0.1秒采样点，与之前固定轨迹滤波评价一致 |
| 评分时域 | 0.5、1.0、2.0秒 |
| 分数定义 | 每次有效轨迹估计的中心预测误差范数；先取每个case全部可评分目标/起点/时域中的**最大值** |
| 校准半径 | 10个case最大误差用 `ceil((n+1)×(1-alpha))` 的有限秩分位；`alpha=0.1` |
| 测试种子 | **60、61、62、63**（全新、不参与校准） |
| 感知 | `noisy_ls5`、`degraded_ls5` 两种固定参数 |
| 包络策略 | `none`=0m；`fixed_030`=0.30m；`offline_q90_2s`=离线得到的额外半径 |
| 动作算法 | 固定第16阶段`two_stage_viability` |
| 仿真时长 | 每case最多22秒（0.1秒控制tick；包含原有0.25秒执行延迟） |
| 试验总数 | 4个测试case × 2种感知 × 3种半径策略 = 24回合 |

命令：

~~~bash
python -m pytest -q tests/test_phase18_envelope_eval.py

python -m lidar_sim.phase18_envelope_eval \
  --scenario two_targets --stress weak_brake \
  --calib-start 10 --calib-seeds 10 \
  --test-start 60 --test-seeds 4 \
  --dt 0.1 --ticks 161 --max-time 22 \
  --output results/phase18-envelope-seeds60-63
~~~

输出为`calibration.json`（记录实际半径、每个校准case的最大预测误差、时域、前提）、`episodes.csv`（24个带物理成功/碰撞/越界/超时结局的原始回合）、`paired.csv`（逐case保留三策略，不丢弃负结果）、`inputs.json`（参数固定记录）和每回合的完整`_trace.csv`/`_metrics.json`。

## 科学限制和后续决策

1. **不是完整长时域覆盖认证**：`q90`仅来自有有效估计时的0.5/1/2s CV中心误差。规划器会检查更长的3秒或制动+停车后备轨迹；把这个静态半径通用于所有规划时刻**不代表其更长时域仍有90%覆盖**。
2. **选择性缺失**：无法生成有效目标估计的时隙被排除在校准分位之外，并由`perception_blocked_steps`及失败结局另报；不可把已评分子集的覆盖率当成全部障碍/全部时刻的概率安全。
3. **有限样本**：10个校准case依赖同一套CV二维目标和固定ego轨迹，跨帧高度相关；按每个case一个最大误差单元，避免把每帧当作独立样本。严格的共形边际覆盖仍需要交换性等假设，而传感观测变化、ID关联、校准目标与闭环观测分布差异都无法从软件证明。
4. **半径可能导致过度保守**：较大的保守圆会同时阻断可行轨迹、增加停车与超时，且停车后动态目标仍有可能侵入。必须将成功、碰撞、超时、通行时间和最小真实净空一起报告，不能只比较碰撞次数。
5. **未来实车迁移**：保持`MovingObstacle.reference_time_s`与`SimulatedPerception`估计World数据契约，将来真实LiDAR前端可替换观测生成器；半径要由真实目标几何及独立预测残差重新校准，并单独验证TF、车辆几何、制动与执行时延。现在不要求用户采集ROS bag。
6. **研究属性**：此实现是占据半径的经验消融，不是原创的共形预测算法或有形式化保证的viability kernel。若结果显示固定与校准半径都不能改善闭环成功率，应保留负结果，继续研究时间相关包络或停车后暴露的动态风险，而非无限调参。
