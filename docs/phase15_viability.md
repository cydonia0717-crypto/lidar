# 第十五阶段：有限深度动作可恢复性试探（探索性消融）

## 实验动机与科学边界

第十四阶段（PR #14）严格复现\`two_targets/weak_brake/seed1\`：约9.7秒开始无安全候选，约11.7秒停稳，16.5秒被骑行者侵入；单纯把最大任务时限从30秒增到35/40秒没有影响。与之不同，seed0在30.10秒完成，30秒“超时”只是任务截止时间选择导致的分类。本阶段所有对比预先固定**35秒任务截止时限**，并记录与旧30秒标准差异；不能混用结果。

已证实存在缺口：基础\`two_stage_bodyframe\`在规划当前两个动作、完整物理刹停和停后6秒占据检查，但它的最佳候选并不检验**下一次决策时是否还能继续找到可行序列**。滚动控制每0.1秒只下发第一段目标；第二段是计划假设，不会被承诺执行。

## 提议：对候选第一段动作进行一次未来可行性探测

增加独立\`two_stage_viability\`；基础模式仍保持完全原样。

1. 原基础\`two_stage_bodyframe\`计算所有第一段×第二段可行序列，仅**完整通过**既有动态目标保守圆/道路矩形/控制延迟/刹车/停后6秒硬条件的第一段候选被允许进入新处理。
2. 依旧按原目标函数排序，选得分最好的**最多3个不同第一段**速度/转向组合。**不会把原本被硬筛掉的动作变成可行**。
3. 对其中每个第一段，把它插入当前真实控制延迟队列的**副本**。按相同0.05秒阿克曼物理积分到未来\`t+0.60s\`，此时0.25秒延迟之后候选已实际执行约0.35秒。只预测该命令持续到探测时刻，不修改真实车辆控制。
4. 对推演轨迹再次执行与原版本相同的时空碰撞检查；随后从未来车辆状态和剩余排队命令重新调用**原基础两阶段规划器**（禁止递归调用探测算法）。如果下一规划状态至少存在1条完整可行序列，记为“有限探测有继续可行候选”。
5. 在前三名之中优先选择**原代价最低且探测中依然有候选**的第一段。如果所有探测都无后续候选，**原封不动返回旧方法的原严格可行动作**，记录\`lookahead_no_viable_shortlist=1\`；不以“高风险也前进”的方式绕过硬约束。
6. 输出\`lookahead_probed\`、\`lookahead_viable\`、\`lookahead_change\`、\`lookahead_child_feasible_count\`和\`lookahead_probe_path_rejected\`，并将总额外计算时间计入每周期规划耗时。

本方法只是一种**有限深度、基于合成理想CV运动的单次未来重规划可行性探测**。模拟未来0.60秒保持第一段指令，并不是真实控制闭环会发生的唯一轨迹（真实控制在每0.1秒更新）。由下一状态有可行候选也不能推导下一下下状态有解，更不能推导递归可行性、零碰撞或实车安全性。该方法有可能**明显增加计算时间**或反而使原本成功的场景失败。参数\`K=3\`和\`0.60s\`预先固定，仅作消融实验，不从已知失败种子中网格搜索最优。

## 公平实验

全部方法固定同一阿克曼底盘尺寸、真实后轴偏置0.55m、制动力0.9m/s²（weak_brake）或1.6m/s²（nominal）、0.25s控制延迟、相同直走廊与理想CV动态目标真值。严格\`pose_gate\`要求终点横向偏差≤0.75m、航向误差≤15°；物理车身与道路统一\`rearaxle_rectangle\`，运动目标仍采用保守圆与相同安全余量。

- 已知失效（开发数据）：\`two_targets/weak_brake/seed0,1\`，每场景新旧均运行35秒上限。seed0原方法30.10秒成功，seed1原方法16.50秒碰撞；
- 留出评估：\`two_targets/weak_brake/seed10,11\`，两种方法同场景、同物理条件；
- 其它未参与设计模板与种子：\`crossing,narrow/nominal/seed40\`，检验前瞻是否产生新碰撞、超时或道路越界。

必须逐种子报告真实成功、碰撞、超时、道路越界、成功行驶时间和计算开销。数据来自GitHub Actions真实仿真及\`episodes.csv\`、\`failure_traces/*.csv\`，不是预设结果。**不能把探索性小样本当论文正式统计证明**。

## 研究约束

- 若新方法不能改善seed1失效，不再通过挑选0.40m偏置或削弱安全margin来制造成功；
- 如果计算耗时超过控制周期，算法暂不能声称实时可部署；
- 完成此消融后优先引入未参与调参的独立种子与更真实的传感器观察（带噪声、漏检、目标状态不确定）；
- 所有结论只限于二维合成CV运动真值与离散采样，不代表实测RoboSense点云、Jetson或形式化安全证明。
