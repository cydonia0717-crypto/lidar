# Phase18 占据包络消融：正式运行结果及失败归因

实验运行：[GitHub Actions #40083404264](https://github.com/cydonia0717-crypto/lidar/actions/runs/40083404264)，原始[Artifact #12555754474](https://github.com/cydonia0717-crypto/lidar/actions/runs/40083404264/artifacts/12555754474)（`calibration.json`、`inputs.json`、`episodes.csv`、`paired.csv`、24回合完整轨迹）。源代码与实验协议：`phase18_envelope_eval.py`及[设计方案](phase18_prediction_envelope_ablation.md)。

## 校准数据（仿真，仅有有效跟踪时评分）

10个独立物理校准case：`two_targets/weak_brake/seed10..19`。固定1.5m/s直行自车，161个0.1秒tick；只评分LS5所报告的有效目标轨迹，对未来0.5/1/2秒的真值CV中心误差取每个case所有被评分起点/目标/时域的最大值。10个独立case、`alpha=.10`，有限秩取第10个，即**最大**的episode误差：

| Sensor | 离线评分的逐时域事件数 | 每个case最大误差的最大值，也即额外半径 |
|---|---:|---:|
| `noisy_ls5` | 9516 | **11.94554 m** |
| `degraded_ls5` | 8247 | **16.65534 m** |

这属于**条件有效跟踪误差最大值**的保守校准诊断；并非真实LiDAR精度、完整轨迹概率保证或任务安全证书。由于高噪声/有限差分、掉点以及大量候选起点中的极端误差，得到的分位值很大。10个episode仅使`k=ceil((10+1)×.9)=10`有有限结果；其统计解释仍依赖不可在此直接验证的独立性、交换性、缺失机制等假设。

## 新测试种子60—63的24个闭环结局

场景统一`two_targets/weak_brake`，`two_stage_viability`不变、`LS5`估计器不变、每次物理动作传输延迟0.25秒、最多22秒。所有物理碰撞依据未膨胀真值半径判定。

| 感知 | 额外半径方案 | 成功/4 | 真实碰撞/4 | 超时/4 |
|---|---|---:|---:|---:|
| noisy_ls5 | 无额外余量0m | 1 | 3 | 0 |
| noisy_ls5 | 固定0.30m | 0 | 3 | 1 |
| noisy_ls5 | 离线分位11.94554m | 0 | 0 | 4 |
| degraded_ls5 | 无额外余量0m | 3 | 1 | 0 |
| degraded_ls5 | 固定0.30m | 0 | 3 | 1 |
| degraded_ls5 | 离线分位16.65534m | 0 | 0 | 4 |

**全量逐帧归因：**

- 两类感知、4个新种子，共8个`offline_q90_2s`回合，**所有221帧中的规划命令`command_speed`均为0.0**（终止帧该字段为空）；没有任何正目标速度指令。
- 初始车辆仍以1.5m/s运动一小段时间，受实际0.25s执行队列和0.9m/s²弱制动约束，在约`x=1.58775m`停车，其后一直保持零速；8个回合都于22秒超时。
- 因此此组“0碰撞”不是避障通行成功，而是**全程拒绝运动的退化策略**。若只报告碰撞率，会错误地把它排名第一。
- 固定0.30m也无稳健改善：轻度退化仍3次碰撞，另一回合超时；强退化从无余量的3次成功降为3次碰撞+1次超时。
- 在seed60—63的强退化下无余量策略仍有3/4成功，和之前seed50—53强退化LS5的0/4成功差异明显，说明少量种子结果受初始几何、噪声实现和时序显著影响；这不是可推广的成功概率估计。

## 从负结果中得到的研究判断

**否定的简单假设**：只要根据离线2秒预测残差校准一个全局半径、并将它等量施加在后续整个规划/制动/停驻预测时域，就能同时改善安全和通过率。

当前证据表明：这一固定半径策略把极端误差直接投影到所有障碍物、所有时刻，可能使所有候选动作无法通过后续可行性检查，形成持续`unsafe_committed_prefix`后备停车。即便小幅固定半径，也会通过改变交会时相造成非单调结果，出现“更保守却更容易碰撞”的案例。

**后续研究方向（未实现、不可抢先写成成功）**：
1. 把一维全局半径改成**时间相关的预测误差包络**；观测龄期、预测时距和误差规模应分别考虑，避免把2秒尾部风险无差别套到立即执行的车辆近场。
2. 保留严格独立的校准/测试seed；同时评价预测覆盖、所用占据面积、物理碰撞、成功、制动、停车和超时；不允许仅优化碰撞率。
3. 检验**停车后动态暴露风险**：即使设置更大安全包络且发出零速度，动态目标仍可能随后进入车辆实际停驻区域。
4. 必须与外部场景基线、不同目标速度/加速度模型以及更广泛的未见种子继续验证。现有2D中心点LiDAR-like模拟仍使用真值对象ID、障碍半径与ego里程信息；不能推出真实ROS/Jetson表现。
