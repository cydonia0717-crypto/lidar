# 第十四阶段：固定终止时间反事实及停车后侵入失效诊断

## 研究背景

[第十三阶段实测报告](phase13_results.md)显示：固定后轴偏置物理真值与规划假设均为0.55m时，\`two_targets/weak_brake/seed0\`在30秒超时，**末帧已恢复行驶，车身中心纵向离终点验收线仅约0.15m**；\`seed1\`在16.5秒碰撞，且撞击瞬间自车已停止，碰撞目标为合成运动骑行者。

不能据此直接把seed0算作成功，也不能把seed1简化成“制动力不足导致撞上目标”。本阶段原样保留所有控制、碰撞、制动、转角和延迟逻辑，用受控回放区分时限截断与长期停车位置侵入。

## 研究设计A：同场景延长终止时限

固定\`two_targets\`、\`weak_brake\`、seed0与seed1，后轴车身中心**物理真值和规划假设都为0.55m**；使用完全一致的阿克曼自行车模型、运动目标合成CV真值、\`pose_gate\`（纵向越线 + \`|y_c|≤0.75m\` + \`|yaw|≤15°\`）、完整6秒停车后备安全验证。

分别独立运行\`max_time={30,35,40}s\`，共6个回合。报告每次的成功、碰撞、超时、道路越界、实际结束时间和每周期规划计算耗时。

- 只有**实际跑到严格终点判据**，才能记录成功；不能拿30秒末帧距离目标线近的事实替代运行。
- 对30秒超时回合，检查它与35/40秒运行在30秒前的所有\`(x,y,yaw,speed,steer)\`状态是否数值一致（阈值1e-7）；不能因增加最大仿真时长改写原轨迹前缀。
- seed1若在16.5秒已碰撞，应在三次重跑中记录同样失败，而非宣称“延长时限修复碰撞”。

## 研究设计B：停车点固定占据的物理侵入

对每回合输出的每个控制周期，计算\`physical_obstacle_gap_m\`，使用**真实物理后轴到车体中心偏置**、同一保守车体外接圆与合成匀速目标的位置（可正可负）。负值为几何圆模型下物理重叠。

仅对车速小于0.1m/s的帧，另做一个**反事实静止测试**：假设车辆从当前时刻起停在原地12秒，按0.05s采样的合成CV目标运动，记录：
- 第一次侵入**物理圆**（gap<0）的相对时刻；
- 第一次侵入**规划包络**（gap<道路安全margin 0.2m + 预测padding 0.12m）的相对时刻；
- 静止12秒窗口内的最小物理目标净空。

注意：这个固定点实验是**诊断反事实**，**不是**该时刻的\`braking_tail + stationary_hold\`实际优化验证，因为后者从不同候选的末状态开始，且前面已有不可取消延迟前缀。不得把一个静止点的12秒风险当作算法永久安全保证，也不得认为只要增加6秒时长便必定完成任务。

同时保留\`emergency\`、\`unsafe_fallback\`、被拒绝的\`prefix/first/second/brake/hold × road/obstacle\`原因、首段可行前进动作比例、车辆姿态、实际零速命令比例和5秒窗口累计。

## 科学边界

目前仍是二维合成目标理想CV真值，没有雷达点云噪声、Hungarian匹配、CV-KF跟踪、运动突然转向/减速或真实底盘标定；\`rear_axle_to_body_center_m=.55\`仍是未经标定的工程假设；目标碰撞检测仍使用车身保守外接圆。离散采样亦不是连续时间无碰撞证明。

本阶段**仅诊断，不修改规划行为**。若35秒下种子0确实完成，意味着原30秒评估出现时限截断，并不代表算法免除长时间停车风险；如果seed1仍被侵入，应分析预测的固定停点与候选后备阶段的矛盾，而非单纯增加进度奖励。
