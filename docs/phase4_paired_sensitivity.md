# 第四阶段：配对对照与参数敏感性实验

本阶段针对导师关心的“**自己的小车如何决策、何时会失败、制动约束究竟带来什么收益**”建立可复核的仿真实验程序，而非继续堆叠算法名称。

## 1. 实验原则

- **同一个 case_id** 的所有算法使用**完全相同**的目标初始位置、速度、车体参数、道路边界、执行延迟、仿真初始速度及环境随机种子。
- 不使用每个方法专门微调的安全膨胀半径，现有 reactive、predictive、delay_aware、braking 已统一配置 `prediction_padding`。方法差异是是否预测移动目标、是否建模控制队列、是否要求完整制动尾迹可行。
- 初始位置的轻微扰动使用确定性随机种子，保证重复运行可得到相同状态轨迹；每种压力条件下各方法使用**相同**的具体扰动。
- 仿真仍然能获取目标的理想 CV 运动真值，没有观测噪声、漏检和目标关联差错；这些结果不说明算法在真实16线激光雷达下已成立。
- 采样碰撞、保守车辆包围圆、不带航向与横向约束的终点成功判据等现有假设都保留，并在元数据中明确写出。

## 2. 压力条件

| stress | 修改因素 | 目的 |
|---|---|---|
| nominal | 延迟0.25s，减速度1.6m/s² | 参照条件 |
| high_delay | 延迟增大至0.50s | 判断忽略指令生效时间是否危险 |
| weak_brake | 最大减速度降低至0.90m/s² | 判断停车尾迹和动作限制的耦合 |
| fast_targets | 行人与骑行者速度×1.50 | 提高时空冲突程度 |
| narrow_road | 道路半宽减少0.50m | 增加道路边界约束 |

制动与延迟均为**明确标注的假设参数**，不是实车标定结果。压力条件每次只改变一个维度，避免不清楚到底是哪一因素造成性能差异。

## 3. 运行命令

```bash
pip install -e '.[dev]'
pytest -q

# 快速演示：单一场景、两种算法、两组独立种子
lidar-eval --scenarios crossing --stresses nominal,high_delay \
  --modes delay_aware,braking --seeds 2 --plot --output results/quick_eval

# 更全面对照（4场景×5压力×10种子×3算法=600次）
lidar-eval --scenarios crossing,two_targets,late_crossing,narrow \
  --stresses nominal,high_delay,weak_brake,fast_targets,narrow_road \
  --modes predictive,delay_aware,braking --seeds 10 \
  --output results/study --plot
```

命令行默认是4场景×5压力×5种子×3算法=300次闭环仿真；可能花费较长时间，尽量在电脑上执行。CI使用微型冒烟测试，避免把600次模拟放入每次PR自动测试。

## 4. 输出和判断原则

- `episodes.csv`：每一次仿真的所有原始记录，包括场景、工况、种子、真实执行延迟、制动减速度、任务成功/碰撞/越界/超时、最低净空、急停周期、制动候选拒绝次数、无安全后备周期数和计算耗时。
- `summary_by_scenario_stress_mode.csv`：按场景×压力条件×方法分别统计成功率、碰撞率、95% Wilson 二项区间、停止次数等。**仅对成功完成回合计算平均通行时间**，避免提前碰撞让算法看起来“更快”。
- `paired_braking_effects.csv`：对每一个完全相同的 case_id 比较 braking - delay_aware 的成功/碰撞变化；正的 collision_change 是**更差**，负的才是更好。
- `metadata.json`：实验模型、参数条件、种子数及已知局限；`rates_by_stress.png`：成功率和碰撞率两项并列统计图，由实际原始仿真数据生成。

Wilson 区间是基础二项描述性统计：同一场景下的种子可能并不独立，不同压力条件还共用相同初始几何，因此**不能当作严格的多组对比显著性检验**。正式论文需要按独立场景组做更严格的配对重采样或分层统计。

**不允许**直接将“碰撞减少多少”从假设改成已达到的仿真结论；先执行足量实验，核对原始数据，再做论文表述。

## 5. 还没有完成的关键问题

1. 当前理想目标运动与实测雷达仍有明显差距，下一阶段添加带噪观测、短时漏检、CV-KF跟踪，并检查预测模型失配。
2. 车辆用了一个包围整车的保守圆，规划检查还是离散时间采样；未来要改为矩形/多圆与连续时间保守扫掠近似。
3. 目标函数的权重还需要独立敏感性实验；不要为了优化特定测试种子而过拟合。
4. 实际动态行人会加速和转向；现有仿真所有障碍物为CV，后续应增加不遵循预测假设的独立运动测试。
5. 同一组仿真场景不应被同时用于修改方法权重和最终检验，需要划出独立留出集。
