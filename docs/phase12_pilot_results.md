# 第十二阶段实际运行结果：后轴参考点、车身中心与终点位姿联合判据

## 数据来源及实验设置

[GitHub Actions Run 39239620168](https://github.com/cydonia0717-crypto/lidar/actions/runs/39239620168)，**75项单元测试通过**、8组配对（新旧各8次，合计16个闭环回合）均成功运行。原始\`episodes.csv\`、\`paired_bodyframe_effects.csv\`、统计图和metadata见该工作流 artifact。

此阶段物理真值重新统一为\`rearaxle_rectangle\`：自行车运动学状态\`(x,y)\`代表后轴中心，几何车身中心按0.55m正向位移变换。两种方法的**实际道路越界、动态目标距离、终点完成**均按这个相同的物理真值裁判。新旧规划只在预测内部是否正确应用车身参考点变换有区别：

- \`two_stage_rectroad\`：旧规划仍将状态位置当作车体中心；虽然姿态旋转矩形，但没有后轴到车身中心偏置；
- \`two_stage_bodyframe\`：规划道路矩形、目标保守圆和路线进度全部使用后轴转换到车身中心的位置。

终点\`pose_gate\`要求**真实车身中心**纵向超过目标阈值（\`goal_x-0.6m\`）、横向绝对误差≤0.75m、航向绝对误差≤15°。属于**正确姿态穿越终点**，不要求最后静止，也未引入新的终点姿态轨迹优化器。所有回合长度最多30秒。CV目标依然使用合成仿真真值。

**合计**：旧模型在相同的后轴物理真值和严格终点判据下**3/8成功、5/8碰撞、0/8超时**；修正参考点后为**6/8成功、1/8碰撞、1/8超时**。两种方法均无道路越界。

这不证明安全性全面提高：\`weak_brake/seed1\`反而从旧模型成功变成新模型碰撞；\`weak_brake/seed0\`由6.05秒碰撞变成30秒超时，**不能把避免一次碰撞当成任务完成**。成功回合的时间不是相同样本集合，不能直接比较平均成功耗时作为速度改进。

## 三、如何正确解释“之前的13/14，现在只有6/8”

第十一阶段13/14使用的是**以状态点为几何中心的物理真值，以及纵向x过线就算成功**。本阶段6/8换成了**物理后轴+车身偏置（包括目标碰撞评估）和横向/航向联合终点验收**，样本场景数量也不一样。因此两者**不能直接得出性能下降或提升的百分比**。

能配对解释的是本报告中**同一场景、同一实际后轴物理真值、同一严格终点判据**的旧/新规划结果。实验显示修正参考坐标有助于若干场景的避碰/达标，同时揭示了弱制动下动态目标冲突和长期停滞问题尚未解决。

## 四、研究局限与接下来的优先级

1. 0.55m后轴到车身几何中心偏置是**工程假设**，没有真实底盘尺寸标定；要进行0.40/0.55/0.70m灵敏度和车辆参考点一致性测试，不能将默认值当成实车实测数据。
2. 位置和航向目标仅对笔直的x轴道路成立；下一步应按参考路径终点局部切线/法线计算横向与航向偏差，并避免状态穿过目标线后才调整航向。
3. 弱制动/种子1出现了从成功到碰撞的反向案例，需要按时间点归因是否有不可取消延迟前缀、车身中心占据判断、刹停动力学或预测窗口限制。
4. 动态目标来自合成匀速CV真值，没有激光雷达点云、目标关联/跟踪不确定性和突然转向/加速；车辆仍用保守圆检查与动态障碍物的占据。
5. 当前\`pose_gate\`是通行而非停车；若论文以“到位停车”为任务，必须增加终点速度上限、停车姿态与稳态保持检验，并重新计算所有结果。
6. 单元测试验证了几何/条件处理，闭环样本仅8组配对；没有递归可行性或实车安全证明。后续还应扩大独立样本并报告碰撞/超时/出界/成功的联合分布。

**适合论文写的结论**：阿克曼后轴运动学参考点与车身碰撞几何中心需要统一，且任务完成标准必须包含终点位置/方向；在相同严格物理真值下，坐标一致化可改变目标碰撞风险判断和闭环避障结果。**不适合直接宣称提出了全新阿克曼理论算法或已实现实车高成功率**。
