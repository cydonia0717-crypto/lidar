# 第十三阶段：后轴至车身中心偏置灵敏度与弱制动失效诊断

## 研究问题

第十二阶段已通过75项自动化测试，在**同一物理后轴真值与终点位姿判据**下，8组配对中旧模型3/8成功、5/8碰撞；新车身偏置规划6/8成功、1/8碰撞、1/8超时。剩余失败：\`two_targets/weak_brake/seed0\` 30秒超时；\`seed1\` 16.50秒动态目标碰撞。本阶段先研究**参数稳健性**，不增加不可证明的新安全机制。

第十二阶段后轴到车身中心\`0.55m\`是人为假设，未实测底盘。以此为真值又以此作为规划参数会隐藏标定偏差。

## 明确分开两种偏置

\`physical_body_offset_m\`是**合成仿真物理真值**下后轴至几何中心的距离；用于真实矩形道路越界、真实目标碰撞圆中心和终点pose_gate。

\`assumed_body_offset_m\`是规划器**认为**的后轴至车身中心的距离；用于候选名义路径、未来制动+停车占据的道路/动态目标硬筛选，以及路线成本。它与物理真值不必相等。

两者范围必须满足\`0 ≤ offset ≤ L/2=0.95m\`，不会通过缩小车辆长宽、修改障碍物半径或降低制动和安全余量作弊。保持轮距1.35m、长1.9m、宽0.85m、目标真值和全部动态制动/延迟。未将偏置值当成真实车体测量数据。

### 实验A：同一物理偏置下的规划标定误差

固定\`physical=0.55m\`，比较\`assumed={0.40,0.55,0.70}m\`。这才可以归因于规划参数不匹配，全部回合共享同一实际几何/目标运动。

### 实验B：车辆几何真值改变时的稳健性

对\`physical={0.40,0.55,0.70}m\`与\`assumed={0.40,0.55,0.70}m\`做3×3网格。这里比较的是**不同假想车体质心/轴位配置**，物理真值已经不同，因此结果不能当作同一物理实例下的配对方法优劣。分层观察是否只在某个偏置配置下成功，是否存在不匹配时退化。

在\`two_targets/weak_brake/seeds 0,1\`运行完整网格；不利用已知失败结果手工优化参数后宣称独立改进。另在未使用的seed10、11固定physical=0.55，对三个规划偏置做留出检验。

## 失效复现证据

新增\`python -m lidar_sim.offset_sensitivity\`，保留：

- \`episodes.csv\`：每回合完整偏置、场景、种子、成功/碰撞/道路越界/超时、轨迹耗时、最小实际净空、历史纵向过线及严格pose_gate状态。
- \`offset_grid_summary.csv\`：按物理偏置和规划偏置分层的完整联合结局及平均规划耗时。
- \`forensics/<episode>.csv\`：弱制动种子0和1的逐周期位置、航向、速度、转向目标、可行两阶段序列、退化状态、各阶段道路/障碍拒绝、实际物理道路净空和**实际动态目标净空**。
- \`forensic_windows.csv\`：每5秒按真实数据累积制动阶段、停车后占据等拒绝事件与真实前进、车速、动作可行性、净空。碰撞回合应复核**物理碰撞发生前的最后离散采样时刻**和延迟队列；超时回合应分辨安全候选耗尽还是明知能动仍停车。

注意不同阶段拒绝计数的候选单位不同；不能直接将跨阶段拒绝事件计算成同一概率。风险指标是CV合成模型下确定性净空，不等于事故概率，不能称其为实车安全证据。

## 论文边界

目前只有直走廊上的二维合成动态目标CV真值、阿克曼低速自行车模型、保守圆目标碰撞和有限离散样本，尚未接入3D LiDAR点云噪声、遮挡、关联与CV-KF。没有形式化保证、没有实车标定，亦没有说明\`0.55m\`是最佳参数。第十二阶段**6/8成功**不能自动转写到偏置不确定条件中。论文应优先报告完整原始结局、失败轨迹、参数不确定影响和适用范围。
