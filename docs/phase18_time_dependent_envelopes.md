# 第18阶段：时间相关障碍物占据包络——仿真优先的消融

> 研究状态：这是一个**可证伪的工程/算法消融**，不是实车实测、安全认证或已证明有效的方法。未来仍可迁移到ROS/Jetson上的轨迹估计输入，但当前完全以二维仿真为主。

## 研究动机

[PR #25的负结果](phase18_envelope_results.md)：独立校准的固定误差半径达到11.94554m（noisy LS5）和16.65534m（degraded LS5）。这导致两个感知等级下全部8个测试回合始终请求零速度，22秒超时。仅比较碰撞数会误认为“零碰撞”最好。固定额外0.30m同样未获得可靠收益。

本轮测试一个更狭窄的假设：**把预测误差和规划安全余量关联到未来预测时距，而非每个未来时刻都使用单一极端半径，是否可以改善安全与任务完成的权衡？**

## 代码与时间定义

在`MovingObstacle`中添加可选的`envelope_anchor_s`、`envelope_horizons_s`和`envelope_padding_m`。`radius_at(t)`计算从**当前规划决策时间**到候选轨迹未来状态时间的间隔`h=max(0,t-t_plan)`，在两个时域节点间线性插值，超过最后节点维持最后一档值。**决策锚点不是障碍物最后观测时刻**；原本的`reference_time_s`继续专用于估计物体的CV位置外推。

~~~text
仿真目标真值（原始半径）─────────────→ 真实动力学/碰撞/任务结局
                 │
                 └─> 合成LiDAR观测 → 因果LS5估计 → 规划时刻包络配置
                                                  │
                          第16阶段viability候选/制动/停车路径上每个时间点
                          用 radius_at(t) 判定碰撞和计算目标代价
~~~

`planner.collision_free`、`two_stage.first_violation_kind`和`decision.trajectory_cost_breakdown`已改为按轨迹采样时间访问`radius_at(t)`；`world.obstacle_clearance`亦支持该可选估计数据。无包络对象的`radius_at(t)`恒等于历史`radius`，所以原第15—17阶段真值规划与物理碰撞判定保持原语义，不应借此宣称新增正式安全证明。

新接口`SimulatedPerception(..., time_padding_horizons_s=..., time_padding_values_m=...)`只为规划估计World附加包络，拒绝无效时戳、NaN/负余量及与非零固定余量混用。每个控制周期重新以本次决策时间锚定，**不会读取当次或未来实际预测误差**。

## 提前固定的四个策略

| 策略 | 0s | 0.5s | 1.0s | 2.0s及更远 |
|---|---:|---:|---:|---:|
| `none` | 0 | 0 | 0 | 0 |
| `fixed_030` | 0.30m | 0.30m | 0.30m | 0.30m |
| `time_ramp`（仅工程启发式） | 0.10m | 0.20m | 0.30m | 0.50m |
| `time_q90`（离线逐时域分位） | q(0.5) | q(0.5) | max(q(0.5),q(1.0)) | max(q(0.5),q(1.0),q(2.0)) |

`time_q90`每个时域分别取10个校准case中**每个case的所有已评分起点/目标的最大误差**，再用`ceil((n+1)×(1-alpha))`分位秩（`alpha=0.1,n=10`，所以是每个时域10个case中的最大值）。为了避免半径随着时域加长而减少，后两个节点用前缀最大值。**这三个单独的条件分位不能保证一个联合90%预测误差包络，尤其不能外推到2秒之后的制动/停车阶段。**

`time_ramp`是一条为了测试通行性而事先确定的工程余量曲线，完全**不具有90%覆盖承诺**。无论何种方法，当没有可靠检测轨迹时仍使用原有不确定场景后备制动，不把`tracks=[]`当作没有障碍。

## 完整闭环实验设计

- 物理：`two_targets/weak_brake`；0.1秒控制周期、0.25秒执行器延迟、原第16阶段`two_stage_viability`。
- 校准：seed10—19、10个独立仿真episode，**仅固定1.5m/s直行ego观察轨迹**，未来0.5/1/2秒CV中心误差；所有独立真值仅在离线评分时可读。
- 测试：seed60—63、4个此前用于PR25验证的固定测试episode。**这些种子已被查看过PR25的失败结局，所以本轮属于沿同一开发集的探索性对比，而不应称为全新盲测。** 如果算法选择据此改变，必须再开辟新的锁定种子集做真正留出评估。
- 感知：`noisy_ls5`和`degraded_ls5`；几何半径/目标CV运动、观测随机数、物理车辆和规划模式在各策略内保持一致。闭环轨迹不同时后续视野/测距也可能变化，不能声称整条时间序列观测必然逐帧相同。
- 4种策略×2感知×4物理case = **32个闭环回合**，每回合最多22秒，记录成功、物理碰撞、越界、超时、真实最小净距、静止步数和感知不可用步数；保存每回合完整trace、`paired.csv`、`episodes.csv`、`calibration_by_horizon.json`、`inputs.json`。

## 必须报告的边界与下一步

- **真值隔离**：只允许在模拟传感器生成过程和决策后评价中访问真实目标位置、速度。规划World中只有LS5估计和按策略预定的半径；回归测试检查原真值半径不受变化影响。
- **覆盖与几何不等价**：中心预测的径向误差分位不能直接等同轨迹联合碰撞安全概率；车体宽度、估计目标半径、离散时域和候选制动阶段还有独立建模误差。
- **时间域溢出**：2秒之外延用最后节点半径，但没有2秒之外的误差校准。若后续制动/停车路径超过2秒，必须明确披露这个盲区。
- **漏检选择偏差**：只有出现有效跟踪的起点能用于分位校准；完全不见的目标和非CV机动目标都不在本次安全范围内。不能把无检测时的制动当作已证实安全。
- **实车迁移**：未来可让真实LiDAR或ROS跟踪器提供相同的目标中心、观测时戳、速度和独立半径估计，但需重新标定定位、时钟、视觉/雷达目标几何、转向制动/执行延迟。当前不用实车数据也不阻断研究进度。
- **论文成果选择**：如果时间相关包络仍导致“始终停车”或碰撞增多，应保留负结果，进一步研究稳健但不永久停车的目标运动预测、安全动作选择或短时段暴露控制；不得调参后仍将seed60—63称为未见独立测试集。
